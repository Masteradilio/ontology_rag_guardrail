# Commercial Pilot Proposal Template

## Pilot Goal

Validate whether Quimera improves audit-ready semantic governance for one concrete RAG or agent workflow.

## Candidate Workflows

1. RAG answer approval for support responses.
2. Agent tool-call authorization before execution.
3. Policy/compliance audit for LLM outputs.

## Duration

Two weeks for a scoped pilot after data access and security approval.

## Inputs

- Synthetic data first.
- Customer data only after explicit approval.
- Frozen ontology/policy snapshot.
- Agreed expected labels for pilot samples.

## Success Metrics

- Setup time.
- False allow rate.
- False block rate.
- Useful abstention rate.
- Audit reconstruction time.
- Developer integration friction.
- Reviewer confidence in proof records.

## Exit Criteria

- Proceed: measurable reduction in review friction or risk exposure.
- Iterate: promising workflow but missing integration or policy behavior.
- Stop: no urgent pain or proof records are not useful to reviewers.

## Claims Boundary

Pilot results are workflow evidence. They are not legal certification, production accuracy claims, or proof that hallucinations are eliminated.
