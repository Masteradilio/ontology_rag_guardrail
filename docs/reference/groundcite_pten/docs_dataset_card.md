# GroundCite-Bench Dataset Card

## Summary

GroundCite-Bench is a deterministic PT-BR/EN seed benchmark for evidence-grounded RAG evaluation. It targets claim-level support, evidence span attribution, unsupported content detection, contradiction detection, and abstention-needed cases.

This dataset is a benchmark seed. It supports reproducible development and controlled experiments, but it does not establish broad real-world generalization by itself.

## Subsets

### GroundCite-Bench Seed

- `data/samples/groundcite_bench_pt.jsonl`: 80 PT-BR generated seed samples.
- `data/samples/groundcite_bench_en.jsonl`: 100 English generated seed samples.
- Generated by `data/scripts/build_groundcite_bench.py`.
- Summary and hashes are generated by `data/scripts/summarize_groundcite_bench.py`.
- Annotation status: `single_pass_gold_seed`.

### PT-BR Human-Adjudicated Seed

- Review file: `data/annotation/pt_human_full_review_with_context.csv`.
- Agreement script: `experiments/scripts/compute_human_agreement.py`.
- IAA result file: `experiments/human_agreement/full_pt_results/pt_human_agreement.json`.
- Adjudication file: `data/annotation/pt_human_full_adjudication.csv`.
- Final labels CSV: `data/annotation/pt_human_full_final_labels.csv`.
- Human-validated JSONL: `data/samples/groundcite_bench_pt_human_validated.jsonl`.
- Current status: human-adjudicated synthetic PT-BR seed, 80 samples and 100 claims.

### English External Gold

- Importer: `data/scripts/import_ragtruth.py`.
- Output when upstream files are provided: `data/samples/groundcite_bench_en_ragtruth.jsonl`.
- Metadata: `gold_source = "ragtruth_human_span_gold"`.
- The deterministic English seed remains separate from imported human span gold.

### Natural-Data Extensions

Offline importers are available for local copies of external PT resources:

- `data/scripts/import_pira.py`
- `data/scripts/import_faquad.py`
- `data/scripts/import_assin2.py`

These scripts do not download data. They convert local files supplied by the researcher and preserve source metadata, license fields, original row IDs, transformation type, and gold-source status.

The project must not claim that these external subsets are present in a paper table unless the generated JSONL files and summaries exist under `data/samples/`.

## Schema

Each sample contains:

- `id`
- `lang`
- `question`
- `contexts`
- `answer`
- optional `reference_answer`
- `gold.claims`
- `gold.unsupported_spans`
- `metadata`

Claim labels are limited to:

- `supported`
- `unsupported`
- `contradicted`

`abstain_needed` is stored as sample metadata/failure type, not as a claim label.

## Intended Use

- Regression tests for GroundCite metrics.
- Controlled PT-BR/EN method development.
- Smoke tests for strict and non-strict experiment pipelines.
- Small reproducibility demonstrations.

## Out-of-Scope Use

- Broad claims about all Portuguese RAG behavior.
- High-stakes factual validation without human review.
- Treating synthetic seed results as final benchmark evidence.
- Treating mock Ragas/DeepEval adapters as paper baselines.

## License

Generated seed records are intended for release as `CC0-1.0`. Imported external datasets retain their upstream licenses and must be cited separately.

## Limitations

- The seed dataset is deterministic and synthetic.
- Unsupported/contradicted templates may be easier than organic RAG failures.
- PT-BR coverage is limited.
- Human adjudication covers the synthetic PT-BR seed. It does not establish broad real-world PT-BR generalization.
